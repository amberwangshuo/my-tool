安装与自定义

导入

  1. 酒馆 → 扩展 → 正则 → 导入 底部打包-冥王星星海版.json 与 选项复制-冥王星星海版.json
  2. 关掉原来的 SP-D①底部打包日夜版 与 SP-A①选项复制日夜版(同开会重复渲染)
  3. 触发条件、作用楼层与原版完全一致,无需改预设

改标签文字

想把「PLUTO SUMMARY」换成别的(比如 ABSTRACT),在脚本里搜 plt-title,改下一行的文字即可。星野密度在 plt-pack-interface::before/::after 的 opacity 里调。

改颜色

所有颜色集中在 CSS 开头的 --plt-* 变量区:--plt-ink 正文、--plt-accent 点缀、--plt-dim 次级灰。夜间在 .plt-pack-wrapper,日间在 .day-mode。
