概念

整个酒馆是一本收录「不可译之词」的辞典。你和角色之间的每一条消息，都是一页词条； 聊天越长，辞典越厚。所有功能都被翻译成辞典的行为——

安装与调整

  1. 酒馆 → 用户设置 → UI 主题 → 导入，选择 不可译-Untranslatable.json
  2. 在背景页设置你自己的背景图——卡片是半透明的，深色/夜景/胶片类底图效果最好
  3. 所有可调项都集中在 CSS 最顶部的甲方调整区：卡片透明度、毛玻璃强度、两支点缀色、行高、全部文案，改中文变量即可，不用懂 CSS
  4. 想换词？九条 nth-of-type 规则里的 content 文字直接改成任何你喜欢的词
