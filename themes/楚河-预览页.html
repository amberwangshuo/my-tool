v2 修订说明

按甲方意见全面返工：① 顶栏改为实底磨砂黑，一条冰线收边，不再透明；② 真正落地图片框架流——每楼一张 140px 大卡头图位，当前为 CSS 自绘的「夜河冷光」占位画，图床直链一填即换真图；③ 卡片解剖学整体重做（Grid 区域布局），与《不可译》无一处同位。

卡片解剖（全新）

大卡头图140px 全宽图位，下缘羽化融进卡身；char 冷月光调，user 压一点朱砂暗火
图上大字冰情观测词渐变字压图（初冰→岸冰→封冻→清沟→冰桥→凌汛→成冰，七楼一循环）；user 楼恒为「过河卒」，暖白到朱砂渐变
反色时间戳章图右上角一枚色章：「渡于 23:47」——char 冰蓝章黑字，user 朱砂章白字
相框方头像46px 方形，暖白照片框，半嵌在图片下缘（电影剧照式）
名字区名字 15px 大字距 → 签名句 → 元数据右对齐一行「渡No.X · 水深X字 · 渡时Xs」
思维链图签式外框，「冰层之下」标题骑在框线上
翻页底部居中一行：无舟 · 渡 2/3 · 仍渡
编辑/更多右下角两枚描边小签「改道」「支流」
输入区四角冰棱角标框文本域 + 打字机「仍要渡么——」 + 朱砂方章「渡」

换图方法（甲方最关心的）

  1. 把图传到 catbox.moe 或 iili.io 拿到直链
  2. 打开 custom CSS 顶部「甲方调整区」，把 --char卡头图 / --user卡头图 改成 url("直链")
  3. 喜欢更满的图可把 --卡头高度 调到 180px
  4. 两岸可以用不同的图；不填时自动显示内置夜河占位画，永不裂图

安装

  1. 把 楚河-TheChuRiver.json 在酒馆 用户设置 → UI 主题 处导入并选择
  2. 背景请放一张你自己的图——卡片是半透明冰面，透得出来
  3. 文案、签名、透明度全部是「甲方调整区」中文变量，改引号里的字即可
