概念

聊天是一场隔河对话。彼岸劝渡，此岸成冰——每一次一来一回，都是题头那两句词在重演，谁也说服不了谁。卒过楚河，落步无回；全界面唯一允许回头的地方，是翻看「已渡之河」（历史记录）。

两色纪律：冰蓝（东流的水）与朱砂（殉道的血色；楚方本就是红方）。全主题无金。

隐喻映射

名字签名行char 楼挂「东流」句（冰蓝），user 楼挂「成冰」句（朱砂），每楼重演一次对话
char 卡头冰情观测词七楼一循环：初冰 → 岸冰 → 封冻 → 清沟 → 冰桥 → 凌汛 → 成冰。河不解冻
user 卡头静态一枚「过河卒」
元数据渡 No.X · 水深 X 字 · 渡时 Xs；时间戳=「渡于」
重roll左「无舟」（冰蓝）· 右「仍渡」（朱砂）· 计数「渡 2/3」
思维链『冰层之下』——水面之下看不见的部分
输入区占位符打字机「仍要渡么——」，发送按钮答一个字：「渡」
加载更多「↑ 已渡之河 · 唯此可回头」（反俄耳浦斯的那个例外）
编辑 / 更多「改道」/「支流」
分割线碎冰浮排，永远缓缓向东流（40s 循环动画）

安装

  1. 把 楚河-TheChuRiver.json 存到酒馆的 public/themes/，或在 用户设置 → UI 主题 处导入
  2. 选择主题《楚河》，字体（文源宋体，zeoseven 415）会自动联网加载
  3. 背景请放一张你自己的图——卡片是半透明冰面，任何背景都透得出来
  4. 想微调？打开 custom CSS 顶部的「甲方调整区」：两句签名、卡头词、透明度、全部文案都是中文变量，改引号里的字即可
  5. 以后找到心仪的图，把 --卡头图 换成图床直链、--卡头高度 调到 120px 以上，卡头即从 SVG 冰纹升级为真图
