# 问卷 → Google Form 生成脚本

把 `Questionnaire_bilingue_v1`（双语问卷，法语版 + 中文版）自动生成为 Google 表单。

## 怎么用

1. 打开 <https://script.google.com>，点 **新建项目**
2. 把 `create_survey_forms.gs` 的全部内容粘贴进编辑器（替换掉里面原有的 `function myFunction() {}`）
3. 顶部函数下拉框里选 **`createFrenchForm`**（法语版）或 **`createChineseForm`**（中文版）
4. 点 **运行**。第一次会弹出授权窗口，选你的 Google 账号 →「高级」→「转至<项目名>（不安全）」→ 允许
   （这个「不安全」提示是因为脚本没走 Google 的应用审核，是你自己写的脚本，正常现象）
5. 底部 **执行日志** 里会打印两个链接：
   - `URL d'édition` — 编辑用，后台改题目
   - `URL de diffusion` — 发给填写者的链接

两个函数可以分别运行，各生成一个独立表单。表单会存在你 Google 云端硬盘的根目录。

- 两个语言版本题号完全一致（A0…E12），方便后期合并数据。

## 几个需要你注意的地方

**匿名与去重。** 脚本已设为不收集邮箱、不要求登录，所以是真匿名。代价是 Google 表单**不记录 IP**，技术笔记里写的「同一 IP 去重」在 Google 表单上做不到。可行的替代：靠 B12 注意力检测题 + 规律作答检测 + 答题时长（在「回复」里导出的时间戳只有提交时间，要测时长得另加一道隐藏时间题）。中文版走问卷星的话，问卷星是有 IP 记录的，去重规则可以只写在中文样本上，但方法论里要说明两边不一致。

**A0 = 否 的人仍然会产生一条记录。** Google 表单没法「不提交就结束」，所以他们会走到第 11 页点提交。这条正好对应你剔除规则里的第一条，导出后按 A0 筛掉即可。

**发布前记得做的事**（技术笔记里已经列了，这里再对一下）：
- 找 3–5 人试填计时，确认真的是 7–9 分钟
- 在正式发链接前，自己先完整走一遍 A1 = 否 和 A5 = 没有 两条分支，确认跳转生效
- 回译流程（Brislin 1970）要在定稿前完成，答辩必问

**改题目。** 所有文案都集中在文件末尾的 `FR` 和 `ZH` 两个对象里，改完重新运行会生成一个**新表单**（不会覆盖旧的）。已经开始收数据之后就直接在 Google 表单后台改，别重跑脚本。
